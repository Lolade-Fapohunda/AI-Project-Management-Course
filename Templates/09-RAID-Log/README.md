# RAID Log

## Purpose

The RAID Log provides a centralized view of **Risks, Assumptions, Issues, and Dependencies** that may affect project delivery.

It helps the Project Manager identify and manage conditions that could impact scope, schedule, cost, quality, or outcomes.

---

## RAID Categories

| Category   | Meaning                                                        |
| ---------- | -------------------------------------------------------------- |
| Risk       | A potential future event that could affect the project.        |
| Assumption | Something believed to be true for planning purposes.           |
| Issue      | A problem that is already occurring.                           |
| Dependency | Something the project relies on or that relies on the project. |

## Risk Response Options

For significant risks, consider:

* Avoid
* Mitigate
* Transfer
* Accept
* Escalate

---

## Issue Escalation

Escalate an issue when:

* The Project Manager cannot resolve it within authority.
* A major milestone is threatened.
* Scope, budget, or schedule is materially affected.
* Security, compliance, or regulatory requirements may be affected.
* A critical business decision is required.
