# RACI Matrix

## Purpose

The RACI Matrix clarifies who is **Responsible, Accountable, Consulted, and Informed** for major project activities and decisions.

---

## RACI Definitions

| Letter | Meaning     | Description                          |
| ------ | ----------- | ------------------------------------ |
| R      | Responsible | Performs the work.                   |
| A      | Accountable | Owns the outcome and final decision. |
| C      | Consulted   | Provides expertise or input.         |
| I      | Informed    | Needs to know the outcome or status. |

## RACI Validation

Ask:

* Does every major activity have an **Accountable** person?
* Is there more than one Accountable person unnecessarily?
* Are Responsible roles clearly identified?
* Are the correct subject matter experts Consulted?
* Are stakeholders being Informed appropriately?
* Are decision rights consistent with governance?
