# Udemy Downloadable Resources Map

## Purpose

This map shows which downloadable resources support each section of the AI Project Management Course.

The **PM Track is the core and required course**.

The **AI Build-Along is optional** and provides additional hands-on technical practice.

Use each resource when directed by the applicable lecture or activity.

---

# Student Resource Flow

**Watch → Download → Apply → Decide → Document → Review**

You should not need to search the course repository to find a required resource.

---

# Course Structure

The course contains:

**13 Course Modules = 13 Udemy Sections**

# Student Resource Access

## Core Resources

All students receive the resources required for the PM Track, including:

* Course Guide
* Syllabus
* Glossary
* Student Resource Map
* Student Start Here
* Project Management templates
* Module exercises
* Capstone resources
* Final Assessment

## Optional Build-Along Resources

Students who choose the optional Build-Along receive the applicable:

* Build-Along milestones
* Technical exercises
* PolicyAssist reference materials
* Dashboard starter resources
* Hands-on application activities

## Instructor-Only Materials

Instructor-only materials are not part of the student download package.

Examples include:

* Instructor Answer Key
* Grading guidance
* Instructor assessment materials
* Instructor recording materials

# Resource Use Standard

Before using a resource, confirm that it:

* Matches the current module.
* Is the correct version.
* Supports the assigned activity.
* Uses the current course terminology.
* Is appropriate for the intended audience.

---

# Capstone Resource Relationship

Course resources build toward the capstone:

**Module Learning → Project Management Artifact → Capstone Evidence → Portfolio Evidence**

Refine and reuse applicable work rather than unnecessarily recreating the same artifact.

---

# Final Resource Principle

Every resource should support one or more of these actions:

**Learn → Apply → Decide → Document → Review**

The resource library is designed to support the complete Project Management learning cycle.
