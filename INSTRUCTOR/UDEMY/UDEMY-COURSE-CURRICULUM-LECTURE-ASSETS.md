# Udemy Course Curriculum Lecture Assets

## Course Overview

The AI Project Management Course is a practical, end-to-end program designed to help Project Managers lead Artificial Intelligence (AI) projects from business problem identification through production and continuous improvement.

The course focuses on Project Management judgment rather than advanced software engineering.

Students learn how to:

* Define and validate AI business problems.
* Identify and manage stakeholders.
* Translate business needs into measurable requirements.
* Manage scope, priorities, backlogs, and releases.
* Understand AI technology and architecture from a Project Management perspective.
* Evaluate data and knowledge readiness.
* Measure AI quality and performance.
* Manage AI risk, security, and governance.
* Coordinate testing, User Acceptance Testing (UAT), and pilots.
* Assess release and deployment readiness.
* Establish production monitoring.
* Manage continuous improvement.
* Make evidence-based Go, Proceed With Conditions, Hold, and No-Go decisions.
* Build professional AI Project Management portfolio evidence.

The course contains a required PM Track and an optional technical Build-Along.

The Petadel PolicyAssist AI project is used as the reference capstone project. Students may use the Petadel reference project or apply the same Project Management process to their own AI product or use case.

---

# Learning Outcomes

By the end of the course, students should be able to:

1. Frame an AI project around a clearly defined business problem and measurable business outcomes.
2. Analyze stakeholders, users, competing objectives, and decision authority.
3. Develop business, functional, non-functional, and AI-specific requirements.
4. Create and prioritize an AI product backlog and define a Minimum Viable Product (MVP).
5. Evaluate AI technology, architecture, dependencies, assumptions, and technical risks.
6. Assess data quality, authority, ownership, versioning, access, metadata, and knowledge governance.
7. Define AI evaluation datasets, metrics, thresholds, and quality criteria.
8. Analyze AI evaluation results and determine appropriate corrective actions.
9. Identify and manage AI-specific risks, security concerns, privacy issues, and governance requirements.
10. Coordinate testing, negative testing, edge-case testing, regression testing, security testing, UAT, and pilot activities.
11. Evaluate production readiness, deployment strategy, rollback readiness, user readiness, and operational readiness.
12. Establish AI monitoring, KPI management, incident response, and continuous improvement processes.
13. Maintain traceability from business problem through requirements, testing, evaluation, UAT, and release decisions.
14. Communicate evidence-based recommendations to technical teams, business stakeholders, and executives.
15. Lead an end-to-end AI project and produce professional portfolio-ready Project Management evidence.

# Purpose

This document defines the lecture assets for the AI Project Management Course on Udemy.

The lecture structure is aligned directly with the 13 GitHub course modules and the Udemy Curriculum Map.

The PM Track is the core course.

The Build-Along is optional and appears only where hands-on technical activity supports the module.

# Standard Lecture Asset Structure

Every lecture should be documented using the following fields:

| Field            | Description                                               |
| ---------------- | --------------------------------------------------------- |
| Lecture          | Udemy lecture title                                       |
| Module           | Corresponding GitHub module                               |
| Format           | Video, exercise, quiz, demonstration, activity, or review |
| Purpose          | What the student should understand or accomplish          |
| Recording        | Instructor content to record                              |
| Resource         | Downloadable resource, if applicable                      |
| Student Activity | Student action, if applicable                             |
| Student Output   | Required evidence or artifact, if applicable              |
| Build-Along      | Optional hands-on activity, if applicable                 |

# Udemy Recording Standard

Each recorded lecture should:

* Focus on one clear learning objective.
* Use direct student language.
* Connect concepts to Project Management practice.
* Define technical terminology when introduced.
* Use realistic examples.
* Avoid unnecessary technical depth.
* Connect major concepts to evidence and decisions.
* Maintain alignment with the corresponding GitHub module.
* Reinforce the course's evidence-based decision framework where applicable.

---

# Udemy Activity Standard

Practical activities should require students to:

**Analyze → Apply → Decide → Document**

Activities should produce useful evidence whenever practical.

Major outputs should connect to the student's capstone and portfolio.

---

# Course-Wide Learning Flow

The instructional experience follows:

**Learn → Apply → Decide → Document → Review**

The AI Project Management lifecycle follows:

**Problem → Requirements → Planning → Technology → Data → Evaluation → Risk & Governance → Testing → Release → Monitoring → Continuous Improvement**

The course connects instructional learning directly to practical Project Management decision-making.

---

# Final Curriculum Asset Standard

The Udemy curriculum should remain:

**Chronological**

Each section follows the AI Project Management lifecycle.

**Aligned**

Each section maps directly to one GitHub module.

**Practical**

Students apply concepts and create evidence.

**PM-Focused**

The course develops Project Management capability rather than advanced AI engineering skills.

**Evidence-Based**

Students use project evidence to make decisions.

**Portfolio-Oriented**

Major activities contribute to professional AI Project Management evidence.

**Flexible**

Students may use the Petadel PolicyAssist AI reference project or their own AI product or use case.
