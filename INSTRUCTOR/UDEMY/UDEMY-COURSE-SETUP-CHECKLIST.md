## Purpose

Use this checklist to prepare, build, review, and submit the AI Project Management Course on Udemy.

The course should be built from the approved GitHub repository and the finalized Udemy planning documents.

The GitHub repository remains the source of truth for course content.

---

# Phase 1: Instructor Account

## Instructor Profile

* [ ] Confirm the Udemy instructor account is complete.
* [ ] Complete Udemy instructor identity verification.
* [ ] Register as a Premium Instructor for paid-course publishing.
* [ ] Add the instructor name.
* [ ] Add the instructor profile photo.
* [ ] Add the instructor biography.
* [ ] Add relevant professional background.
* [ ] Review the instructor profile for professional presentation.

---

# Phase 2: Create the Udemy Course

## Course Information

* [ ] Create a new Udemy course.
* [ ] Enter the approved course title.
* [ ] Enter the approved course subtitle.
* [ ] Select the appropriate course category.
* [ ] Select the appropriate course topic.
* [ ] Define the appropriate experience level.
* [ ] Enter the course description.
* [ ] Enter the learning outcomes.
* [ ] Enter the intended learner information.
* [ ] Enter the course requirements.
* [ ] Include the required Udemy AI-use disclosure in the course description when applicable.

## Course Positioning

Confirm that the course is presented as:

**AI Project Management**

and not as:

* AI engineering training
* A coding bootcamp
* A data-science course
* A machine-learning engineering course

The course should clearly communicate that students learn how to manage AI projects without needing to become AI engineers.

# Phase 5: Record Course Content

## Recording Preparation

Before recording:

* [ ] Review the applicable module.
* [ ] Review the lecture asset.
* [ ] Confirm the learning objective.
* [ ] Confirm examples and terminology.
* [ ] Confirm the student activity.
* [ ] Confirm the downloadable resource.
* [ ] Confirm any Build-Along demonstration.

## Recording Standard

Each lecture should:

* Focus on one clear learning objective.
* Address students directly.
* Use professional language.
* Explain technical terms when introduced.
* Connect technical concepts to Project Management decisions.
* Use realistic examples.
* Avoid unnecessary technical depth.
* Reinforce evidence-based decision-making.

# Phase 9: Capstone Setup

Confirm that Module 12 includes the complete required capstone framework.

The **Capstone & Portfolio is a required Project Management component of the course**.

Students do not need to build or deploy an AI application to complete the PM capstone.

The optional Build-Along provides additional hands-on technical practice but does not replace or add a separate capstone requirement.

Students may use:

* Petadel PolicyAssist AI as the reference project.
* Their own AI product or use case.

## Required Capstone Portfolio Evidence

Students must be able to produce:

1. Project Charter
2. Discovery & Stakeholder Analysis
3. Requirements Specification
4. Product Backlog & Release Plan
5. AI Architecture & Technology Assessment
6. Data Readiness & Knowledge Governance Assessment
7. AI Evaluation & Quality Report
8. AI Risk, Security & Governance Plan
9. Testing, UAT & Pilot Plan
10. Release & Deployment Plan
11. AI Monitoring & Continuous Improvement Plan
12. Decision Log
13. Risk Register
14. Requirements Traceability
15. Executive Summary
16. Final Go / Proceed With Conditions / Hold / No-Go Recommendation
17. Final Presentation

Confirm that these artifacts collectively demonstrate the student's end-to-end Project Management decision-making capability.

---

# Phase 10: Build-Along Setup

The Build-Along is optional.

Use the 12-milestone structure:

**Milestones 1–12 = Modules 1–12**

Module 13 is the core Final Assessment.

The Build-Along must not be presented as a separate required course.

Confirm that:

* [ ] Students understand the Build-Along is optional.
* [ ] Students can complete the PM Track without technical implementation.
* [ ] Technical activities are aligned to the corresponding PM module.
* [ ] Petadel PolicyAssist AI is presented as the reference project.
* [ ] Students may apply the PM process to their own AI product or use case.
* [ ] Milestone 12 supports the capstone but does not create a separate technical graduation requirement.
* [ ] There is no required Build-Along milestone for Module 13.

* [ ] Deliverables align with the capstone.
* [ ] Student and instructor materials are separated.

* [ ] Petadel remains a reference project.
* [ ] The own-project option remains available.
* [ ] No unnecessary duplicate activities have been introduced.
* [ ] No unsupported claims are included.
* [ ] No confidential information is included.

* [ ] The Capstone is clearly distinguished from the Final Assessment.
* [ ] The Final Assessment is clearly identified as Module 13.
* [ ] The optional Build-Along does not create additional completion requirements.

# Phase 15: Assessment Review

The Final Assessment is **Module 13** and is separate from the Module 12 Capstone & Portfolio.

The Final Assessment is required for **all students**.

Participation in the optional Build-Along is not required to take or complete the Final Assessment.

Before publishing the Final Assessment:

* [ ] All 15 questions are present.
* [ ] Scenario questions assess Project Management reasoning.
* [ ] Evidence is required where appropriate.
* [ ] AI Project Management competencies are represented.
* [ ] Release decisions use the approved decision framework.
* [ ] KPI questions use agreed targets.
* [ ] Security and governance are represented.
* [ ] UAT is represented.
* [ ] Monitoring is represented.
* [ ] Continuous improvement is represented.
* [ ] The Final Assessment tests application of course concepts rather than completion of the optional Build-Along.
* [ ] Passing standard is 80% or higher.
* [ ] Instructor Answer Key is not available to students.
