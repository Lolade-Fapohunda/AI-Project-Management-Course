# Welcome to the AI Project Management Course

Welcome.

This course is designed to help you learn how to **manage AI projects from business problem through continuous improvement**.

You do not need to be an AI engineer or software developer to complete the core course.

The course focuses on the Project Management decisions required to lead AI products and cross-functional teams.

# Choose Your Learning Path

Everyone completes the **PM Track**.

The **Build-Along is optional**.

## PM Track

The core course teaches you how to:

**Define → Plan → Govern → Evaluate → Test → Release → Monitor → Improve**

You will work with AI Project Management concepts, frameworks, scenarios, templates, and decisions.

## Optional Build-Along

If you want hands-on experience, complete the Student Build-Along using:

[Petadel PolicyAssist AI](https://github.com/Lolade-Fapohunda/AI-Project-Management-Course/tree/main/PolicyAssist-App)

You may follow the Petadel reference project or apply the process to your own AI product or use case.

# Your Goal

By the end of this course, you should be able to manage an AI product through the complete lifecycle:

**Business Problem → Requirements → Scope → AI Solution → Data → Evaluation → Risk → Testing → Release → Monitoring → Continuous Improvement**

Most importantly, you should be able to answer:

> **What does the evidence tell us, what decision should we make, and what should happen next?**

That is the core skill of an effective AI Project Manager.
