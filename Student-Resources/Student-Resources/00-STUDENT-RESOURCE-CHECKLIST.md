# Student Resource Checklist

Use this checklist to make sure you have access to the resources needed to complete the AI Project Management Course.

## Before You Begin

* [ ] Read the Course Guide
* [ ] Review the Course Syllabus
* [ ] Review the Glossary
* [ ] Access the GitHub course repository
* [ ] Review the Student Resources folder

## Project Management Resources

* [ ] Access the Project Management and AI templates
* [ ] Use the appropriate template for each course activity
* [ ] Save completed artifacts as evidence of your work
* [ ] Keep your project decisions and supporting evidence organized

## Student Build-Along — Optional

* [ ] Review the Build-Along Start Here guide
* [ ] Choose your participation option:

  * [ ] Petadel PolicyAssist reference project
  * [ ] Your own AI product or use case
* [ ] Complete the Build-Along milestones you choose to complete
* [ ] Test and document your work
* [ ] Record the PM decisions made at each stage

## PolicyAssist AI Application

Build-Along participants:

* [ ] Access the PolicyAssist application resources
* [ ] Review the application from a Project Manager's perspective
* [ ] Follow the applicable Build-Along instructions
* [ ] Document observations, results, and decisions

You are not expected to become an AI engineer or write production-level AI code.

## Capstone

* [ ] Complete the AI Project Management capstone
* [ ] Review the Petadel PolicyAssist reference example
* [ ] Organize your project evidence
* [ ] Document major PM decisions
* [ ] Complete the capstone submission
* [ ] Prepare your portfolio package

## Portfolio

* [ ] Create your portfolio case study
* [ ] Add your strongest project artifacts
* [ ] Include evidence supporting major decisions
* [ ] Document your role and contributions
* [ ] Translate project work into interview talking points
* [ ] Prepare resume achievement statements
* [ ] Prepare your professional profile summary

## Final Assessment

* [ ] Complete the Final Assessment
* [ ] Complete the scenario-based questions
* [ ] Complete the release decision exercise
* [ ] Interpret the KPI scenario
* [ ] Provide an executive-level recommendation
* [ ] Complete the final PM challenge
* [ ] Complete the final reflection

## Final Completion Check

Before considering the course complete, confirm that you can explain:

**Problem → Requirements → Scope → AI Solution → Data → Evaluation → Risk → Testing → Release → Monitoring → Improvement**

You should be able to demonstrate:

* [ ] Evidence-based decision making
* [ ] Business alignment
* [ ] AI product understanding
* [ ] Risk and governance awareness
* [ ] Testing and release readiness
* [ ] KPI interpretation
* [ ] Executive communication
* [ ] Continuous improvement thinking

## Final Standard

The objective is not simply to complete files or assignments.

The objective is to demonstrate that you can manage an AI product through its lifecycle and make sound Project Management decisions based on evidence.

**Problem → Evidence → Decision → Action → Outcome**
