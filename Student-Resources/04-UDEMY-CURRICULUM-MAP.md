# Udemy Curriculum Map

## Purpose

This document maps the AI Project Management Course into the Udemy curriculum.

The Udemy curriculum is aligned directly with the 13-module course structure in the GitHub repository.

The structure is chronological and follows the AI Project Management lifecycle:

**Problem → Requirements → Planning → Technology → Data → Evaluation → Risk & Governance → Testing → Release → Monitoring → Capstone → Assessment**

The **PM Track is the core course**.

The **Build-Along is optional** and is included within the applicable sections rather than treated as a separate course.

The Petadel PolicyAssist AI project is the reference project. Students may use the Petadel reference project or apply the same Project Management process to their own AI product or use case.

---

# Standard Udemy Section Pattern

Each section should follow a consistent learning pattern:

**Learn → Apply → Decide → Document → Review**

Where applicable, the student experience should include:

1. Instructional video
2. Example or demonstration
3. Practical activity
4. Project Management decision
5. Template or artifact
6. Optional Build-Along
7. Knowledge check or review

# Udemy Curriculum Design Standard

The curriculum should remain:

**Chronological**

Each section follows the AI Project Management lifecycle.

**Aligned**

Each Udemy section maps directly to one GitHub module.

**Practical**

Students apply concepts rather than only watching lectures.

**PM-Focused**

The course teaches AI Project Management rather than advanced AI engineering.

**Evidence-Based**

Students make decisions using requirements, test results, evaluation results, risks, UAT, KPIs, and other project evidence.

**Portfolio-Oriented**

Major activities contribute to professional Project Management evidence.

**Flexible**

Students may use the Petadel PolicyAssist AI reference project or their own AI product or use case.
