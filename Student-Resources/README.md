## 5. Student Build-Along

The optional Build-Along provides hands-on experience using the Petadel PolicyAssist AI project.

Resource: `Student-Build-Along/`

The Build-Along follows the AI Project Management lifecycle from foundation through the capstone.

You may:

* Follow the Petadel PolicyAssist project.
* Apply the same PM process to your own AI project.

The Build-Along is optional. The PM Track remains the core course.

The Build-Along includes hands-on activities aligned with Modules 1–12.

There is no separate technical Build-Along milestone for Module 13. The Final Assessment is required for all students.

The course includes a working Petadel PolicyAssist AI application for hands-on learning.

## 7. Petadel PolicyAssist Capstone

The capstone demonstrates the complete AI Project Management lifecycle using the fictional Petadel Technology Services PolicyAssist AI project.

Resource: `Capstone/Petadel-Policy-Assist/`

You may use the Petadel PolicyAssist AI reference project or apply the same Project Management process to your own AI product or use case.

## 9. Final Assessment

Complete the Final Assessment in Module 13 after completing the course lifecycle.

Resource: `Modules/13-Final-Assessment/`

The Final Assessment validates your ability to:

* Apply AI Project Management concepts.
* Make evidence-based decisions.
* Interpret KPIs.
* Evaluate release readiness.
* Communicate with executives.
* Manage AI projects through the full lifecycle.

The Final Assessment is required for all students.

Participation in the optional Build-Along is not required to complete the Final Assessment.

# Recommended Student Path

Follow this sequence:

**Course Guide → Syllabus → Modules → Templates → Optional Build-Along → Capstone → Portfolio → Final Assessment**

Students who do not participate in the Build-Along simply continue through the required PM Track.

---

# Completion Standard

You are not simply completing assignments.

You are building evidence that you can manage an AI project from:

**Business Problem → Requirements → Scope → AI Solution → Data → Evaluation → Risk → Testing → Release → Monitoring → Continuous Improvement**

The goal is to leave the course with practical AI Project Management knowledge, reusable artifacts, and portfolio-ready evidence.
