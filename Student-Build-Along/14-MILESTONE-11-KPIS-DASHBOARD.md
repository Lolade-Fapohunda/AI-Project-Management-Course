# Milestone 11 — KPIs & Dashboard

## PM Objective

Use measurable performance data to determine whether the AI product is delivering the expected business and product outcomes.

## Important

This milestone is part of the core PM Track.

All students complete this milestone, whether or not they participate in the optional Build-Along.

## Hands-On Objective

Analyze AI product performance using KPIs and a dashboard.

## PM Activities

Evaluate:

- Business outcome KPIs
- AI quality KPIs
- User experience KPIs
- Operational KPIs
- Security KPIs
- Targets
- Actual performance
- Trends
- Thresholds
- Corrective actions

## PolicyAssist Example KPIs

Use the following targets as the reference example:

| KPI | Target |
|---|---:|
| Policy search-time reduction | ≥50% |
| Retrieval accuracy | ≥90% |
| Answer accuracy | ≥90% |
| Hallucination rate | <2% |
| Citation correctness | 100% |
| Unsupported-question refusal | 100% |
| Response latency | ≤10 seconds |
| User satisfaction | ≥85% |
| Critical security incidents | 0 |

Students using their own AI project should define appropriate KPIs and targets for their product.

## Dashboard Analysis

For each KPI, evaluate:

**KPI → Target → Actual → Trend → Threshold → Action**

Ask:

1. Are we meeting the target?
2. Is performance improving or declining?
3. Has a threshold been breached?
4. What action should the PM take?
5. Does the result create a risk to the product or business outcome?
6. Does the issue require escalation?

## Build-Along Activity

Students participating in the technical Build-Along may implement a dashboard in the application.

Students who do not participate in the technical Build-Along will use the provided dashboard/example and complete the same PM analysis.

## Deliverable

Complete a KPI dashboard analysis documenting:

- KPI
- Target
- Actual
- Trend
- Threshold
- PM interpretation
- Recommended action
- Escalation decision

## PM Decision

Based on dashboard results, determine whether the product should:

**Continue → Improve → Escalate → Reassess**

Document the evidence supporting your decision.

## PM Checkpoint

Before moving forward, you should be able to answer:

**Is the AI product delivering the expected business and product outcomes, and what should the PM do based on the performance data?**
