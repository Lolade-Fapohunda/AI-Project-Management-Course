# Milestone 11 — KPI Dashboard Lab

## PM Objective

Use product performance data to monitor an AI product, identify issues, and make informed PM decisions.

## Important

KPI and dashboard management is part of the core PM Track.

All students complete the PM analysis.

The technical dashboard build is optional.

---

# Part 1 — Everyone: Analyze the Dashboard

Using the provided dashboard/example:

1. Review each KPI.
2. Compare Actual vs. Target.
3. Identify improving or declining trends.
4. Identify any threshold breaches.
5. Determine which issues require action.
6. Recommend corrective actions.
7. Document your PM decision.

Use:

**KPI → Target → Actual → Trend → Threshold → Action**

## PM Deliverable

Complete the KPI Dashboard Analysis.

---

# Part 2 — Optional Hands-On Dashboard Build

Students who choose the technical Build-Along will create a simple KPI dashboard using Streamlit.

You will NOT build the dashboard from scratch.

You will receive starter code and modify it step-by-step.

## Step 1 — Add KPI Data

Add the provided KPI names, targets, and actual values.

## Step 2 — Create KPI Cards

Display the key performance indicators so a PM can quickly see product health.

## Step 3 — Add Target vs. Actual

Create a simple visual comparison between the target and current performance.

## Step 4 — Add a Trend Visual

Display performance over time so the PM can identify improvement or decline.

## Step 5 — Add Status / Threshold Logic

Configure the dashboard to identify whether each KPI is:

- On Target
- Needs Attention
- Below Threshold

## Step 6 — Run the Dashboard

Launch the Streamlit application and review the dashboard as a PM.

## Step 7 — Interpret the Results

Identify:

- KPIs meeting target
- KPIs missing target
- Declining trends
- Threshold breaches
- Business or product risks

## Step 8 — Make the PM Decision

Based on the dashboard, determine whether the product should:

**Continue → Improve → Escalate → Reassess**

Document the evidence supporting your decision.

---

# PM Checkpoint

Before completing this milestone, you should be able to answer:

**What is the product telling us through its KPIs, and what should the PM do about it?**

Technical Build-Along participants should also be able to demonstrate a functioning KPI dashboard.
