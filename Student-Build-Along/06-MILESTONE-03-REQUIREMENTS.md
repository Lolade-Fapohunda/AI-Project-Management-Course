# Milestone 3 — Requirements

## PM Objective

Translate stakeholder needs into clear, measurable AI product requirements.

## Hands-On Objective

Connect requirements to the capabilities the AI product must provide.

## PM Activities

- Define functional requirements
- Define non-functional requirements
- Define AI-specific requirements
- Define security requirements
- Define measurable acceptance criteria
- Identify requirement dependencies
- Identify requirement risks

## Hands-On Activity

For at least five requirements:

1. Identify the stakeholder need.
2. Define the product requirement.
3. Define how the requirement will be measured.
4. Create an acceptance criterion.
5. Identify a related risk or dependency.

## Deliverable

Create or update the requirements documentation for your project.

Each requirement should answer:

**What must the product do, why does it matter, and how will we know it works?**

## PM Checkpoint

Before moving forward, you should be able to explain:

**How did stakeholder needs become measurable product requirements and acceptance criteria?**
