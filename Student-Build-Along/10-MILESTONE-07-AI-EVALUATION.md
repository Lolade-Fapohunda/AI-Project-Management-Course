# Milestone 7 — AI Evaluation

## PM Objective

Determine whether the AI product is performing well enough to meet its defined quality and business requirements.

## Hands-On Objective

Test AI responses against defined scenarios and evaluate the results using measurable criteria.

## PM Activities

Evaluate:

- Answer accuracy
- Retrieval accuracy
- Hallucination rate
- Citation correctness
- Unsupported-question refusal
- Response latency
- User satisfaction

## Hands-On Activity

1. Select at least five representative user questions.
2. Define the expected result for each question.
3. Run each question through the AI product.
4. Compare the response with the expected result.
5. Check whether supporting evidence was retrieved.
6. Check whether citations are correct.
7. Identify unsupported or incorrect claims.
8. Record the results.
9. Determine whether the product meets the defined quality targets.

## Deliverable

Complete an AI evaluation results table containing:

- Test question
- Expected result
- Actual result
- Pass/Fail
- Metric evaluated
- Issue identified
- Recommended action

## PM Decision

Based on the evaluation results, determine whether the product should:

**Proceed → Hold → Return for Improvement**

Document the evidence supporting your decision.

## PM Checkpoint

Before moving forward, you should be able to answer:

**Is the AI performing well enough to move forward, and what evidence supports that decision?**
